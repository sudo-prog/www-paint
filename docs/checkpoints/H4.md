## 1. Goal

Harness **H4**: *"feedback store + retrieval; similar refs produce closer
proposals (5.3/5.4)."*

The loop's "learns from each success and from user input" half. Every attempt —
`(reference → profile knobs → metrics → rating)` — is stored, so a **similar
reference later starts closer**: the proposer warm-starts from the best prior
result for a perceptually-near image.

## 2. Design — `js/engine/memory.js` (new, pure, deterministic, node-only)

| Export | Role |
|---|---|
| `averageHash(pixels, w, h)` | a 64-bit **average hash** (8×8 luminance grid thresholded at its mean) — a coarse perceptual signature; near-identical references collide. |
| `hamming(a, b)` | bit distance between two hex hashes. |
| `profileSignature(knobs)` | order-independent key for a knob vector. |
| `createMemory({ maxEntries })` | the store: `record` · `list` · `retrieve` · `best` · `warmStart` · `size` · `clear` · `toJSON` · `load`. |

**Retrieval** ranks stored entries by Hamming distance to the query hash
(ascending), then by score (descending), then insertion order — deterministic.
Only entries within `maxDistance` count; so "similar" is an explicit, tunable
predicate, not a hand-wave.

**Warm start** returns the nearest entry's knob vector shaped for
`propose.searchProfile(base, image, { init })`.

**Honest scope (harness §3):** this is *not* a trainable model and *not* a full
perceptual metric — aHash is a coarse signature. The store is **bounded**
(guardrail #2) and **records wins and losses** (guardrail #5); a rejected
high-scoring profile is kept as negative signal. Persistence (IndexedDB /
localStorage) is a thin adapter over `toJSON()` / `load()`; no backend here.

## 3. Evidence

```
$ node tests/engine.test.js
Passed: 113   Failed: 0        # was 105; +8 H4 tests
```

8 new tests: hash determinism + collision + symmetry; hash separation of very
different images; record/list/size/best with ratings (losses kept); retrieval
ordering (distance then score) + determinism; warm start (nearest knobs; null
when nothing is near); `toJSON`/`load` round-trip + version refusal; bounded store
eviction; signature order-independence + a warm start seeding `searchProfile`.

Measured (48² references; a red disc on a blue field vs. the same disc +15
brightness, vs. a black/white split):

| reference | averageHash | vs. disc |
|---|---|---|
| disc | `3c3c000000003c3c` | — |
| disc, +15 brightness | `3c3c000000003c3c` | **0** |
| black/white halves | `f0f0f0f0f0f0f0f0` | **32** |

`warmStart(disc+15)` → `{ init: { coverage: 1.2, elongation: 1.4 }, from: 0,
distance: 0, score: { simMae: 97.9 } }` — the near reference retrieves the exact
knobs of the close stored case.

`node scripts/visual-regression.cjs` → **pass=9 fail=0 error=0** (new module is
not on the app load path).

## 1. Goal

Give the engine a proper local-orientation field so strokes can follow image
structure (Hertzmann-style edge-following) instead of the raw per-pixel Sobel
gradient direction that `alignToGradient` uses today.

Why a structure tensor and not just the gradient? The raw gradient is noisy and
undefined where the gradient is near zero; it has no notion of *confidence*. The
structure tensor integrates the gradient's outer product over a window, yielding:

- a **stable dominant orientation** (the eigenvector), and
- a **coherence / anisotropy** measure (the eigenvalue ratio) that says how much
  to trust it.

References (roadmap §3): wet-paint-flow, Kyprianidis & Kang (coherence-enhancing
diffusion / orientation fields), Hertzmann 1998.

## 2. Design

`analyzer.js` gains a pure, dependency-free, worker-safe function:

```
computeStructureTensor(gx, gy, width, height, { radius = 3 })
  → { orientation, coherence, energy, Jxx, Jyy, Jxy, width, height }
```

- **J** = window-integrated outer product of the Sobel gradient. The window is a
  separable **box blur** (`radius` half-size) — a cheap, deterministic stand-in
  for the literature's Gaussian weighting.
- Eigenvalues of the 2×2 tensor: `λ₁,₂ = (Jxx+Jyy ± √((Jxx−Jyy)² + 4·Jxy²)) / 2`.
- **coherence** = `(λ₁ − λ₂) / (λ₁ + λ₂ + ε)` ∈ [0, 1] — anisotropy.
- **orientation** = the TANGENT (edge-following) angle, i.e. the principal
  gradient orientation `½·atan2(2·Jxy, Jxx−Jyy)` rotated by 90°, wrapped to
  [0, π). Lines are π-periodic, so it is stored in [0, π).
- **energy** = `λ₁` normalised to [0, 1] against the image max (structure amount).

`analyzeImage` computes this by default (`options.structure`, `structureRadius`)
from the RAW Sobel gradients (before edge-magnitude normalisation) and attaches
`analysis.structure`. Passing `{ structure: false }` disables it.

Also added:
- `sampleStructure(arr, w, h, x, y)` — bilinear sampler (mirrors `sampleEdge`).
- `structureDebugRGBA(structure)` — Node-safe RGBA buffer: **hue** = tangent
  angle (full wheel), **saturation** = coherence, **lightness** = energy.

### Generator wiring (`alignToStructure`)

New setting `DEFAULT_SETTINGS.alignToStructure = false`. When true (and the
analysis carries a structure map), the stroke angle at each position is rotated
from the gradient angle toward the local **tangent**, blended by coherence:

```
strokeAngle = angleLerp(gradAngle, nearestPeriodicAngle(gradAngle, tangent), coherence)
```

So coherence 1 → strokes lie ALONG edges; coherence 0 (flat) → keep the gradient
angle. `nearestPeriodicAngle` folds the π-periodic tangent to the nearest
equivalent of the directed gradient angle, avoiding 180° flips.

**Determinism guard:** with `alignToStructure: false` the angle block is
byte-for-byte equivalent to the previous code (same value, no extra RNG draws),
so existing generation is unchanged — confirmed by the visual-regression net.

  (π/2 / 0 / 3π/4); flat image → zero energy & coherence and no NaN; determinism;

  baselines (determinism preserved; the change is additive).
- Cost: on a 512×512 image `analyzeImage` ≈ 104 ms without structure vs ≈ 110–136 ms
  with it — the tensor is a small fraction (k-means still dominates). Candidate
  for worker offload in Phase 6.

## 4b. UI surfacing — the STRUCTURE controls

The app paints with the **Painter**, which has its *own* structure tensor
(`Tan`/`Coh`/`Edge`) driving `guidedShape()`. Its alignment strength was
hard-wired (`0.3 + 0.65·coh`, jitter `0.12`) and not adjustable. Two knobs were
carved out and exposed:

- **Painter** — new options `structureAlign` (0..1) and `alignJitter` (radians),
  read with defaults `1` and `0.12` so the **output is byte-identical by
  default**; used in `guidedShape()`. Defaults flow through unchanged, which is
  why the Phase 0 baselines still hash-match.
- **Engine** — both the direct and the worker Painter paths forward
  `this.settings.structureAlign` / `alignJitter`.
- **Controls** — a new **STRUCTURE** section (`#structure-section`) holding the
  **Smart Mode** toggle (moved out of BRUSH), the **Edge Follow** slider
  (`structureAlign`, shown %) and the **Align Wobble** slider (`alignJitter`,
  shown in degrees), plus a one-line hint. See `docs/UI_CONTROLS.md`.

**Verified in a real browser** (`scripts/structure-controls-probe.cjs`):
the section renders with the toggle and both sliders (Edge Follow 100%,
Align Wobble 7°), and driving the real engine on a diagonal-ramp image through
`settings` measurably changes output:

| structureAlign | early-stroke \|cos\| vs tangent | mean stroke length |
|---|---|---|
| 1 (default) | 0.998 | 99.3 px |
| 0 | 0.950 | 77.6 px |

i.e. Edge Follow steers stroke *seeding* toward the field and yields longer
traced strokes. (Final-painting alignment converges for both because the
hill-climb re-optimises every stroke — documented, not hidden.)

Also hardened `sampleStructure` to clamp out-of-range coordinates (stroke
centroids can fall outside the image; an out-of-range index returned `NaN`) —
found by this probe, +1 test.

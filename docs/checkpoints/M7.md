## 1. Goal

`js/engine/outlines.js` (NEW) — edge-following outline extraction over an
`analyzeImage()` result, returning open polylines largest-first so the optimiser
can lay outline strokes first.

**Frozen interface (IF-3), as issued:**

```js
export function extractOutlines(analysis, opts = {}) -> {
  width, height,
  outlines: Array<{ points: Array<[x, y]>, strength: number }> // open polylines, largest first
}
```

---

## 2. Design

1. **Threshold** the analyzer's normalised Sobel `edges` map into an edge mask,
   **retaining the magnitudes** (a binary mask makes every thresholded pixel
   equal, so the walk cannot tell a ridge from noise).
2. **Seed** a walk only from a *contour* pixel — one whose strongest edge
   neighbour is at least as strong as it is. Isolated noise speckle never seeds.
3. **Walk** greedily to the strongest unvisited edge neighbour, never stepping
   back the way it came; each walk carries its own visited set.
4. **Claim** a walk's pixels in the shared mask only after it finishes, so a
   single walk can close its loop without being cut short.
5. **De-duplicate** near-identical contours (>=80% shared pixels) that a closed
   loop produces when seeded from several points.
6. **Filter** by `minLength` and `minStrength`, sort largest-first, cap at
   `maxOutlines`.

No canvas, no DOM, no randomness — deterministic and worker-safe.

## 4. Two defects the tests caught (both fixed)

| # | Defect | Cause | Fix |
|---|---|---|---|
| 1 | A closed contour was truncated — the square's left edge went untraced | All walks shared **one** visited set, so the second walk died at its first step on a pixel the first had already claimed | Each walk gets a **private** visited set; the shared mask is updated after the walk completes |
| 2 | 64 near-identical outlines for one square | After fix #1 every seed re-walked the same closed loop | De-duplicate: drop any outline with >=80% of its pixels already kept |

Defect #2 was reported by a vision review, not by the assertion suite — the
green tests passed on 64 duplicate contours. **Lesson: a green suite does not
prove the output is sane; the count and the picture both have to be checked.**

## 7. Hand-off notes for BE

- The module is **not wired** into `optimizer.js` (BE-owned). Expected use:
  call `extractOutlines(analysis)` and commit one stroke per returned polyline
  before the main schedule, largest-first.
- `strength` is the **mean edge magnitude** along the walk (0..1), so it can be
  used to prioritise which outlines to spend strokes on.
- `minStrength` (default 0.4) is the noise gate. On a pure-noise field the walk
  still finds local ridges with mean magnitude ~0.45–0.52; a real contour scores
  ~0.92. Set `minStrength` above ~0.6 to reject noise outright.

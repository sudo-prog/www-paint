# P2.2b — Layer-aware scoring (Phase 2.2 closer)

**Date:** 2026-11-12 · Agent: BE (ThinkPad) · **Status: done** · Stream **B2**
(`HANDOFF-BE.md`) · Roadmap Phase 2.2

---

## 1. Goal

Phase 2.2 delivered per-layer **generation** (per-band styles, live
`setLayerStyle`, multi-layer composite). It left *scoring* whole-frame: the AI
harness (`score.js`) measured one number for the whole image, so a band that
reproduced its tonal range badly hid behind three good ones. Close that gap — a
**layer-aware** score the per-layer styles can be optimised against.

## 2. Design

Two additive pieces, both canvas-free and deterministic (plain `node`):

### 2.1 `metrics.js` — masked measurement

| Export | Role |
|---|---|
| `weightedSsimLuma(a, b, w, h, weight)` | the 8×8 block SSIM of `ssimLuma`, but each block contributes to the mean in proportion to its **mean mask weight** — a band covering 22 % of the frame is measured on its own pixels only. |
| `maskedMetrics(rendered, target, weight, w, h)` | MAE / `simMae` / weighted SSIM over the pixels a soft mask selects, plus `support` = the mask's mean weight. |
| `maskedMetricsVsTarget(rendered, targetPixels, weight, w, h)` | the RGBA-bytes convenience wrapper. |

Key property: a mask of **all ones reproduces the whole-frame numbers exactly**
(unit-tested), so a band score is directly comparable with the frame score and
with the other bands.

### 2.2 `score.js` — the layer-aware primitive

`scoreProfileLayers(profile, image, opts)` runs the engine of record once, then:

1. computes the same soft tonal masks the layer system renders with
   (`computeTonalMasks`, `masks.js` IF-1 — consumed, not modified);
2. scores the rendered image against the target **within each band**
   (`TONAL_BANDS` = background / shadows / midtones / highlights);
3. returns a **coverage-weighted composite** plus the whole-frame `overall`, the
   per-band breakdown and the coverage fractions.

`scoreProfile` is untouched → fully backward-compatible.

**Honest scope.** The headless engine of record emits a **single** shape list
(multi-layer *rendering* is the canvas engine's job, Phase 2.3), so this
decomposes the composite render by tonal band rather than scoring separately
rasterised layers. Per-band *render* scoring arrives with the multi-layer
headless path. Bands with zero coverage are inert: `support: 0`, weight 0 in the
composite.

```

New tests: all-ones mask equality · zero mask (mae 0 / support 0 / ssim 0) ·
half-covering support fraction · `weightedSsimLuma` isolates a band · the
per-band breakdown is deterministic and its composite is the coverage-weighted
band MAE · `scoreProfile` unchanged.

```

Baselines **unmoved** (no module here is on the app load path).

Measured (96² disc-on-field, profile `painterly` / 300 strokes, seed 7):

| band | simMae | ssim | coverage |
|---|---|---|---|
| background | 100.000 | 0.0000 | 0.000 |
| shadows | 98.957 | 0.9752 | 0.787 |
| midtones | 98.235 | 0.9599 | 0.213 |
| highlights | 100.000 | 0.0000 | 0.000 |
| **composite** | **98.804** | — | Σ 1.000 |

The probe image has only two populated bands (a red disc = midtones on a blue
field = shadows); the empty bands carry weight 0 and do not move the composite.
Composite (98.804) matches the whole-frame score — the expected property when the
masks tile the frame.

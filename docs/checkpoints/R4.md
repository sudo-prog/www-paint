## 2. Design — `optimizer.js` region-fill pass

`regionFillPass(budget)` (mirrors the R3 `regionInitPass`):

1. segment the target into connected components (the same `regions.js` CCL + PCA
   the R3 init uses);
2. lay **one broad flat ellipse per component** — extent from the component's
   principal-axis eigenvalues (`0.5·√(12·λ)`, margin-scaled), orientation from the
   component's angle, colour = the component's mean — **largest area first**;
3. commit each via the shared `commitShape()` (so the pass updates the running
   paint buffer and the coarse→fine schedule then refines on top of it).

This is the classical *"wash in the large flat values before detail"* step. It is
**opt-in**: default `regionFill: 0` → the pass emits nothing and output is
**byte-identical to R3** (unit-tested). New options: `regionFill`,
`regionFillMinArea`, `regionFillMaxAreaFrac`, `regionFillMargin`, `regionFillAlpha`.
Deterministic — no RNG.

## 3. Evidence

```
$ node tests/engine.test.js
Passed: 123   Failed: 0        # was 120; +3 R4 tests
```

New tests: default 0 is a no-op and **matches an explicit `regionFill: 0`
byte-for-byte**; `> 0` emits fill strokes, **keeps the exact stroke budget**,
emits a broad fill ellipse first, and is deterministic; `resolveOptions` passes
the option through; a pure-noise target correctly blocks in nothing.

Measured — `scoreProfile` (400 strokes, seed 12345, 96² targets; `regionFill`
0 vs 0.3):

| target | off simMae | 0.3 simMae | Δ | fillUsed | strokes |
|---|---|---|---|---|---|
| blobs | 98.46 | 98.47 | **+0.01** | 2 | 400 → 400 |
| rings | 97.05 | 97.12 | **+0.07** | 2 | 400 → 400 |
| smooth | 99.69 | 99.69 | 0.00 | 14 | 400 → 400 |
| noise | 75.77 | 75.77 | 0.00 | 0 | 400 → 400 |

**Honest read:** the gain is *small but non-negative* — it helps the structured
images a little (rings +0.07, blobs +0.01), is flat on smooth/noise, and never
costs strokes (the budget is exact). Because it is marginal, it is left **off by
default** rather than churning the parity baseline for +0.07.

`node scripts/visual-regression.cjs` → **pass=9 fail=0 error=0** (baselines
unmoved; `regionFill` is default-off and the app painter is untouched).

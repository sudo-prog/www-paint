## 2. Design

### 2.1 `renderer.js` — the one call site the IF-2 contract asked for

`Renderer` now owns an optional wet state `{ sim, canvas, ctx, opts }`:

| Method | Role |
|---|---|
| `setWetMedia(opts\|null)` | build/replace (or clear) the sim + its offscreen canvas at the render target size. Called on `setSize` so the grid always matches. |
| `_wetDeposit(shape)` | per stroke in `renderLayer`: `sim.deposit(cx, cy, r, color0, { amount, water })`. |
| `_wetComposite(ctx)` | once per pass: `sim.dry(1/60)` → `sim.compositeInto(wetCtx)` → draw the wet canvas **MULTIPLY** over the layer. |
| `setSmudge(n)` / `_applySmudge(ctx,w,h,n)` | deterministic 3×3 blend (no RNG). |
| `getHeightBuffer()` | the sim's `paperHeight` field (1.5), or null. |
| `mediaModelToWetOpts(m, seed)` (exported) | maps a profile `mediaModel` → `createWetSim` opts; `kind:'dry'`/absent → `null`. |

**Why MULTIPLY.** `compositeInto` paints opaque paper: white where there is no
pigment. Multiplying a white source is the identity, and a pigmented source
darkens — so the wash adds **absorption on top of the strokes already drawn**
instead of wiping the layer. Satisfies the frozen contract (the sim is
composited after the style draw) without hiding the render.

**Idempotency.** The sim accumulates pigment across deposits, so `renderAll`
rebuilds it from a fresh sheet at the **start of every pass** — `render()` is
therefore deterministic (same input → same output). The wash and smudge are
composited **once per pass**, in `renderAll` (not per layer).

**Calibration.** Per-stroke pigment is a fraction of the stroke (`amount =
alpha × 0.004`): `compositeInto` saturates (coverage `1−e^(−6m)`) by `m≈0.5`, so
a several-hundred-stroke wash at full amount multiplies to **solid black**. The
probe measured exactly that (mean luminance 0.09) before calibration; 0.004
lands a translucent wash (160 → 119).

**Scope note.** The wet pass runs in the **single-layer** path only; per-layer
wet rendering is a later refinement (the sim is one shared grid). Multi-layer
mode is unchanged.

### 2.2 `engine.js` — the wiring

- `generate()` builds the wet pass from `opts.wetMedia` (wins) **or** the
  profile's `settings.mediaModel` (via `mediaModelToWetOpts`) — a dry/absent
  model leaves it off, so profiles without a media model are byte-identical.
- `opts.smudge` sets the smudge amount.
- New passthroughs: `engine.setWetMedia()`, `engine.setSmudge()`,
  `engine.getHeightBuffer()`.

## 5. Honest assessment / next

- The wet pass overlays a **wash derived from every stroke**, drawn on top of the
  styles' own direct draw. The deeper form — wet styles *deposit instead of draw*
  — is the natural refinement, and wants per-layer (multi-layer) wet rendering.
- Smudge is a single 3×3 blend pass; a directional, stroke-following smudge is
  future work.
- 3.3 clears the Phase 3 exit: the engine now consumes `mediaModel` and drives
  wetsim; 1.5 gives the smudge + height buffer. Phase 3 can be marked done.

**Date:** 2026-11-12 · Agent: Mac / AIR HERMES · Stream **M9** (`docs/MAC-TASKS.md` Round 2)

---

## 1. Goal

`js/styles/shaping.js` (NEW) — a **data table** so the optimiser can shape
strokes per style.

**Frozen interface, as issued:**

```js
export function resolveShaping(styleName) -> { minSize, maxSize, elongation, order, regionFill }
```

- `minSize` / `maxSize` — preferred stroke size range (px)
- `elongation` — preferred stroke aspect (>= 1)
- `order` — preferred paint order (one of the `order.js` modes)
- `regionFill` — how much flat region fill the style can carry, 0..1

Unknown style → documented `SHAPING_DEFAULTS`.

---

## 2. Design

- **Data only** — no functions in the table, no DOM, no randomness. The table is
  plain numbers plus one `order` string per style, so it is unit-testable and
  serialisable.
- **Every registered style has an entry.** `unshapedStyles()` returns the
  registry names missing from the table; the test suite asserts it is empty by
  iterating the live registry (51 styles), so a newly registered style cannot
  silently fall through to defaults.
- **A fresh copy is returned.** `resolveShaping` builds a new object, so
  mutating the result cannot corrupt the table (asserted).
- **Grouped by category** (`draw`, `paint`, `graphic`, `craft`, `3d`) so the
  values read as a coherent set rather than 51 arbitrary rows.

Values were chosen from each style's own `defaults` where those exist (e.g.
`charcoal` and `oil` carry a larger stroke range; `string`/`thread`/`stitch`
are highly elongated; `wash`/`watercolor`/`gouache` accept the most region
fill) and set to documented defaults elsewhere.

## 7. Hand-off notes for BE

- **Not wired** into `optimizer.js` (BE-owned). Intended use: look up
  `resolveShaping(styleName)` and use `minSize`/`maxSize` to bound the stroke
  sampler, `elongation` to bias the aspect of generated shapes, `order` as the
  default paint order for that style, and `regionFill` to gate the R4
  region-fill pass per style.
- The **nine pinned styles are present** in the table (`pencil ink watercolor
  oil charcoal marker cross-hatch halftone graphic`). Improving those styles'
  *rendering* is a BE re-baseline decision; the shaping table only describes
  preferred geometry and does not touch their output.
- If a style is added to the registry later, the test suite fails until it has
  a shaping entry — that is deliberate.

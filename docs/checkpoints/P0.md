## 2. 0.1 — Style Profile schema

- Single portable object: `global + layers[] + effects[] + mediaModel + styleDNA + provenance`.
- **Integration-aligned**: `effects[]` is structurally identical to LAYERS
  `effect-stack` (`core/params/opacity/blend/mask/enabled`), and a Style Profile
  wraps into a LAYERS `preset`. This makes Phase B of the integration strategy
  largely a no-op on the schema side — see `docs/INTEGRATION_STRATEGY.md` §7.2.
- Tonal roles fixed to the engine's named layers
  (`background/shadows/outline/midtone/highlights`, `PaintingEngine.LAYER_NAMES`).

## 3. 0.2 — Visual regression harness

Design:

- `tests/visual/regression.html` builds a **deterministic** procedural test image
  (seeded PRNG, no `Math.random`), runs the real `PaintingEngine` (`useWorker:false`),
  exports PNG and returns a SHA-256 of the bytes.
- `scripts/visual-regression.cjs` serves the repo, drives headless Chromium
  (playwright-core), compares hashes to `tests/visual/baselines.json`, writes
  reference PNGs under `tests/visual/baselines/` with `--update`.
- Core cases: pencil, ink, watercolor, oil, charcoal, marker, cross-hatch,
  halftone, graphic — fixed `seed` (3047602159), `count` 700, 256×256.
- Two built-in guards:
  1. **width invariant** — any emitted `S` stroke with `params[6] <= 0` fails the
     run by name (this is what caught defect #2);
  2. **gradient-arg capture** — a failing `createRadialGradient` reports its args.

Baselines are machine- and browser-build-specific by construction; re-baseline
deliberately with `--update` on a verified change, never to silence a red run.

## 4. Defects found and fixed (blocking 0.2)

### 4.1 `Renderer.exportImage()` returned `undefined` (PNG/JPG export broken)

`js/engine/renderer.js` renders onto an offscreen canvas but never encoded or
returned it, despite `@returns {Promise<Blob>}`. Consequently
`PaintingEngine.exportPNG()` / `exportJPG()` resolved to `undefined`, and the
app's export buttons (`js/ui/app.js` → `_handleExportImage` →
`_downloadBlob(undefined)`) **failed for PNG/JPG**. (`exportLayerImage` and the
stale `js/ui/app.bundle.js` copy already returned correctly — only the live
source path was broken.)

Fix: encode and return the blob; also normalise `image/jpg` → `image/jpeg` (the
engine passed the former, which the canvas API does not recognise, so JPG export
silently produced PNG bytes).

### 4.2 `Painter.KIND['S']` was off by one → negative stroke widths → render crash

`KIND` maps each param index to its mutation kind. `S` was declared `'pppppsa'`
(7 entries for an 8-entry array), shifting width to `'a'` (angle) and leaving the
angle unhandled. So `mutate()` nudged stroke **width by an unbounded gaussian**:

- width could go **negative**; `watercolor` then threw
  `IndexSizeError: createRadialGradient … r1 < 0` (measured: 2 of 700 strokes),
  hard-failing that style's render;
- `y2` was wrongly clamped via the `'s'` rule.

Fix: `S: 'ppppppsa'` (six coordinates `p`, width `s`, angle `a`). One character;
root cause verified by instrumenting the mutation stages, not guessed.

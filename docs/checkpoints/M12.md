## 1. What "measurably improved" means here

`docs/MAC-TASKS.md` says "state the metric". The metric is **local contrast** — the mean
8×8-block luminance standard deviation of the exported PNG — measured on a fixed
deterministic test image (the same one `tests/visual/regression.html` uses), same seed
(3047602159), same stroke count (700), same 256×256 canvas, through the real engine
(`PaintingEngine`, `useWorker:false`). Reported alongside ink coverage, Sobel edge
density, blank-block ratio, and distinct-hue count.

Harness: **`scripts/style-polish.cjs`** (NEW). `--before` / `--after` capture PNGs +
`metrics.json`; `--compare` diffs them. It serves the repo, decodes the PNG in the page,
and computes the metrics in Node.

Raw before/after data: `docs/research/m12/before/metrics.json`,
`docs/research/m12/after/metrics.json`, with `before/*.png` and `after/*.png`.

## 3. Defects found and fixed

Each was found by the browser probe, then reproduced in isolation before fixing.

### 3.1 `bokeh.js` — rendered a blank canvas for every shape

`_renderArea` line 191 read `this.spacingFactor`. That property does not exist on the
instance — the value lives at `this.defaults.spacingFactor` — so it was `undefined`:

```
spacing = colSize * undefined * 4  →  NaN
cols     = Math.ceil(120 / NaN) + 2 →  NaN
for (let i = 0; i < NaN; i++)      →  never runs
```

`inkCoverage` was **0.0000** and `blankRatio` **1.0000** on a 700-stroke render.
Reproduced by instrumenting `_drawBokehCircle`: **0 calls** on a shape whose loop
arithmetic produced 49 valid centres.

**Fix:** `this.defaults.spacingFactor`. Coverage 0 → 0.9999.

### 3.2 `riso.js` — `ReferenceError: path is not defined`

`_renderStroke` ended with a grain loop that called `ctx.stroke(path)`, but `path` is
declared only in `_renderArea`. Every S-type shape threw.

**Reproduced:** `page.evaluate` returned `ReferenceError: path is not defined` at
`riso.js:175` on shape index 2, 5, 9… — i.e. every stroke, not a rare path.

**Fix:** the grain is now real short strokes along the centreline
(`beginPath`/`moveTo`/`lineTo`/`stroke`), using the same seeded RNG.

### 3.3 `pastel.js` — stamp index walked off the end of the point array

`_renderStroke` advanced `j` in **two** places: the `while (j < n - 2 && cum[j] < d) j++`
guard *and* a `j++` at the end of the loop body. After a few iterations `j` reached
`P.length`, so `P[j]` was `undefined` and `P[j][0]` threw.

**Reproduced:** `TypeError: Cannot read properties of undefined (reading '0')` at
`pastel.js:193`, on shapes 13, 27, 29, 34… — roughly every 15 strokes.

**Fix:** clamp `j` to `[1, n-2]` after the while loop; drop the trailing `j++`.

### 3.4 `glitch.js` — a bare `ctx.clip()` outside save/restore

`_renderArea` did `ctx.restore()` then `ctx.clip()` with no matching `save()`. That
clipped the **whole canvas** to whatever path was current and was never restored, so
subsequent shapes drew into a shrinking region — `inkCoverage` was **0.1083** and the
render showed a hard edge band.

**Fix:** the clip is re-established inside a `save()`/`restore()` pair.

### 3.5 `wash` tide line was invisible at wash opacity

Not a crash — a measurement catch. The first version scaled the tide-line alpha by
`opacity`, and a wash runs at `opacity: 0.15`, so the rim alpha came out at ~0.05 and
the contrast moved only 5.39 → 5.75. Corrected to scale off the base alpha
(`o * (0.35 + tideDarken*2)`); contrast then reached **12.76**. The lesson is recorded
in the source comment so it is not re-made.

## 4. Polish changes (the non-defect half)

All additive, all seeded (the RNG is the style's own `rngFor`), all clipped to the
style's own shape so nothing leaks onto the canvas:

- **`wash`** — drying tide line along both shoulders + granulation speckles.
- **`gouache`** — dry-brush drag streaks + pigment flecks.
- **`confetti`** — lit top edge / shaded underside on each piece; lit apex on triangles.
- **`tape`** — tonal bands across the width + longitudinal fibre grain.
- **`calligraphy`** — darker wet centreline + lighter dry shoulders, clipped to the nib band.
- **`dots`** — denser ink core inside a softer rim.
- **`graffiti`** — fine overspray mist, concentric tonal falloff, denser centreline particles.

## 6. Tests

**`tests/style-polish.test.js`** (NEW, 11 tests, no DOM/canvas):

1. bokeh reads `spacingFactor` from defaults, not the instance
2. bokeh loop bounds are finite and positive (no NaN)
3. riso has no undeclared `path` reference in `_renderStroke`
4. riso grain strokes a real path
5. pastel clamps the stamp index before indexing
6. pastel walk stays in bounds on a zero-length stroke
7. glitch never calls `clip()` with an empty save stack
8. glitch saves/restores balance
9. glitch clips are inside a save block
10. **every non-pinned style renders degenerate shapes without throwing**
    (zero-length, all-zero, tiny — 41 styles × 4 shapes)
11. M12-touched styles are deterministic (identical draw-call log across two renders)

Test 10 is the regression guard for the three dead styles: it runs every non-pinned
renderer against degenerate geometry so a future index/clip bug fails in Node rather
than silently blanking a canvas.

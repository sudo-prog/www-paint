# Checkpoint R2 — Structure-guided multi-scale

**Date:** 2026-11-11 · Agent: BE (ThinkPad) · Track R (`docs/CLEANROOM.md`) · **Status: done**

---

## 1. Goal

Milestone **R2** (`CLEANROOM.md` §4): *structure-guided multi-scale — coarse→fine;
strokes follow the shared structure tensor (roadmap 1.2/1.3). Beats the R1 baseline.*

R1 folded coverage and colour onto the target but the render stayed **soft**:
every dab was roughly the same size, so hard contours read as mush. R2 introduces a
coarse→fine pass schedule so fine, edge-aligned strokes resolve contours instead of
smearing them.

## 2. Research (cited techniques)

- Hertzmann, *Painterly Rendering with Curved Brush Strokes of Multiple Sizes* (1998)
  — the classical **coarse-to-fine painterly schedule**: paint large strokes against a
  blurred reference, then progressively smaller strokes against sharper references,
  so low-frequency layout is laid down first and fine detail is added last.
  Cited in `docs/REFERENCES.md` / `ROADMAP.md` §3.3.
- Structure-tensor SBR (Kyprianidis & Kang; roadmap 1.2) — the orientation/coherence
  field already produced by `analyzer.computeStructureTensor`, reused here to orient
  and elongate the fine strokes along edges.

Re-derived from the published technique; no code or identifiers taken from any
implementation.

## 3. Design

`js/engine/optimizer.js` gained a **pass schedule** on top of the R1 core:

1. **Coarse→fine reference pyramid.** A separable box blur (`blurRGB`) builds a
   progressively sharper reference per pass: the coarsest pass works against
   `blur(target, coarseBlur·baseR)`, the finest against the **unblurred** target.
   The blur is a cheap, deterministic stand-in for the Gaussian pyramid — its job is
   a *region average* the coarse strokes can lay down, not a photometric filter.
2. **Budget split, coarse-first.** `buildScalePlan()` allocates the stroke budget
   across passes with a decreasing geometric weight (`pass k → 1/(k + weightBias)`),
   so the coarse pass gets the largest share. Total stays exactly the requested
   `count` — any budget a coarse pass leaves unspent (it ran out of error) carries
   forward to the next, finer pass.
3. **Scale-aware structure guidance.** Dab elongation along the structure-tensor
   tangent is *weak* at the coarse scales (broad coverage stays roughly round) and
   *strong* at the fine scales (`elongMul` 0.5 → 1.0), so the smallest strokes are
   the ones that hug edges.
4. **Per-pass residual.** Before each pass the residual map is recomputed against
   that scale's reference; the R1 placement + signed-`D` hill-climb, size clamp and
   local-core colour sampling are unchanged, so the honest-objective guarantees from
   R1 carry over. `scales: 1` collapses to the exact R1 single pass.

New options (all defaulted, `scales: 3`): `coarseRadius`, `fineRadius`, `coarseBlur`,
`fineElongation`, `weightBias`.

**Defaults were tuned by measurement, not by eye** — a Playwright sweep drove the
*real* parity harness (`tests/parity/harness.html`) images and its independent MAE+SSIM
across ~20 parameter variants; the chosen set (`coarseRadius 1.6`, `fineRadius 0.64`,
`coarseBlur 0.6`, `weightBias 2.0`) was the variant that improved **both** metrics on
**all three** structured images.

## 4. Evidence — parity bench (seed 12345, 400 shapes, 256², independent MAE + SSIM)

| image | R1 simMae / SSIM | **R2 simMae / SSIM** | Δ simMae | reference simMae / SSIM | R2 gap to ref |
|---|---|---|---|---|---|
| blobs  | 93.22 / 0.8315 | **97.52 / 0.8671** | **+4.30** | 99.54 / 0.9882 | 2.02 / 0.121 |
| rings  | 97.93 / 0.8454 | **98.01 / 0.8522** | **+0.08** | 99.52 / 0.9751 | 1.51 / 0.123 |
| smooth | 98.66 / 0.9251 | **98.78 / 0.9317** | **+0.12** | 99.67 / 0.9883 | 0.89 / 0.057 |
| noise  | 80.97 / 0.0287 | 80.89 / 0.0256 | −0.08 | 81.17 / 0.0645 | 0.28 / 0.039 |

Every structured image improves on **both** simMae and SSIM. `blobs` — the image with
the most large flat fields and hard edges — gains **+4.3 simMae and +0.036 SSIM**, and
its gap to the reference nearly closes (6.32 → 2.02, effectively at the R6 gate).
`noise` is the metric's deliberate **negative control** (a field of white noise nobody
can fit — the reference itself only reaches 81.17): R2 dips there by 0.08 simMae,
i.e. the coarse pass spends a little budget on a blur that white noise cannot exploit.
That is the honest cost of the schedule, recorded rather than hidden.

structured target, multi-scale determinism). `node scripts/visual-regression.cjs` →

## 6. Honest assessment / next

R2 sharpens contours measurably, but dabs are still **smooth ellipses** — shape
vocabulary is uniform, so the painter has no *stroke*-shaped primitive to exploit the
edges it now finds. That is what **R3 (CCL + PCA stroke init)** is for: initialise
strokes from connected components and their principal axes so elongated features get
elongated, edge-locked strokes with far fewer marks. R2's scale plan and elongation
hook are the substrate it builds on.
